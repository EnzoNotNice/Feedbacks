## المميزات الرئيسية

- **تقييم تلقائي ببطاقات مصممة**: عند تحديد روم الفيدباك يتحول أي رأي يكتبه العميل تلقائياً إلى بطاقة مصممة بصورته واسمه وعدد النجوم والتقييم، مع دعم أمر `/feedback` ونموذج اللوحة
- **لوحة رئيسية ثابتة ورسالة Sticky**: تبقى اللوحة الرئيسية في أعلى الروم مع تحديث إحصائياتها، وتنزل أسفل القناة رسالة خفيفة متجددة برابط مباشر للوحة عند كل تقييم جديد
- **بوابة المراجعة والموافقات**: إمكانية تفعيل المراجعة المسبقة لإرسال الطلبات أولاً إلى قناة الإدارة مع أزرار القبول والرفض وسبب الرفض
- **ردود وتعديلات مباشرة**: إمكانية الرد الرسمي من الإدارة على أي فيدباك أو تعديل العميل لتقييمه مع تحديث البطاقة فوراً
- **إحصائيات ولوحات صدارة (`/reviews`)**: استعراض الآراء بصفحات وفلاتر متقدمة مع بطاقة إحصائيات بصرية وترتيب أعلى الطاقم والعملاء
- **نظام حماية وتحكم كامل**: اشتراط رتبة العميل وفترة التهدئة والحد الأدنى للأحرف وقائمة الحظر ومنع الدردشة العشوائية في روم الفيدباك
- **سجلات تدقيق مفصلة**: توثيق فوري لكل عملية نشر أو قبول أو رفض أو تعديل أو رد أو حذف في قناة السجلات
- **مزامنة تلقائية كاملة**: رفع أيقونات البوت المخصصة وتسجيل الأوامر دون تكرار تلقائياً عند التشغيل

## أوامر البوت

### أوامر العملاء والاستعراض

| الأمر | الصلاحية | الوصف |
| :--- | :---: | :--- |
| `/feedback` | حسب الإعدادات | كتابة وإرسال فيدباك وتقييم جديد للخدمة |
| `/reviews list` | الجميع | تصفح التقييمات مع الفلترة حسب النجوم أو الخدمة أو العضو |
| `/reviews stats` | الجميع | عرض إحصائيات السيرفر وتوزيع التقييمات |
| `/reviews top` | الجميع | عرض ترتيب أعلى الطاقم وأكثر العملاء تقييماً |
| `/reviews view` | الجميع | عرض تفاصيل فيدباك محدد وتعديله لصاحبه |
| `/help` | الجميع | عرض دليل الأوامر والقوائم التفاعلية |

### أوامر الإدارة

| الأمر | الصلاحية | الوصف |
| :--- | :---: | :--- |
| `/feedback-admin channel` | إدارة السيرفر | تحديد روم الفيدباك وتفعيل التحويل التلقائي |
| `/feedback-admin setup` | إدارة السيرفر | فتح لوحة الإعدادات التفاعلية للقنوات والرتب والقيود |
| `/feedback-admin panel` | إدارة السيرفر | إرسال لوحة الفيدباك الرئيسية في الروم المحدد |
| `/feedback-admin client` | الطاقم / الإدارة | منح أو سحب رتبة العميل المعتمد |
| `/feedback-admin request` | الطاقم / الإدارة | إرسال دعوة فيدباك مباشرة لعضو معين |
| `/feedback-admin reply` | الطاقم / الإدارة | إضافة رد رسمي أسفل أي فيدباك منشور |
| `/feedback-admin delete` | إدارة السيرفر | حذف فيدباك محدد مع تسجيل السبب |
| `/feedback-admin services` | إدارة السيرفر | إضافة أو حذف أو عرض قائمة الخدمات المتاحة |
| `/feedback-admin blacklist` | إدارة السيرفر | حظر أو رفع الحظر عن عضو من نظام الفيدباك |
| `/feedback-admin export` | إدارة السيرفر | تصدير سجل التقييمات بصيغة JSON أو CSV |

## طريقة التشغيل

### 1. تحميل المشروع وتثبيت الاعتماديات

```bash
git clone https://github.com/USERNAME/Feedbacks.git
cd Feedbacks
npm install
npm run build
```

### 2. إعداد ملف البيئة

انسخ ملف `.env.example` إلى `.env` وأدخل بيانات البوت:

```env
DISCORD_TOKEN=توكن_البوت
DISCORD_CLIENT_ID=آيدي_التطبيق
```

> [!IMPORTANT]
> احرص على تفعيل **Server Members Intent** في بوابة مطوري ديسكورد لقراءة رتب العملاء وأعضاء السيرفر بشكل سليم

### 3. التشغيل

```bash
npm start
```

أو للتشغيل بوضع التطوير المباشر:

```bash
npm run dev
```

## تغيير توكن البوت

عند تغيير التوكن في ملف `.env` ثم تشغيل البوت بـ `npm start` يتعرف النظام تلقائياً على التطبيق الجديد ويرفع جميع الأيقونات الـ 37 المخصصة ويوثقها في `emojis.json` ويزيل أي أوامر مكررة دون أي خطوات يدوية
